# edu-robot

机器人研发、AI创意造物课程与学生平台的资料库。包含19个机器人及配套技术档案、75个不同上游GitHub仓库的76份固定提交快照，以及课程方案、项目思维导图和参考文档。

当前优先候选是小纸壳机器人：先复刻纸板外壳、OLED表情、摸头和双轴头部动作，记录物料、接线、供电、校准与验收，再研究原创角色和对话扩展。

## 目录内容

每个项目文件夹包含详细说明、配套生态与代码导读、逐仓阅读记录、来源版本和参考图片。GitHub来源放在各项目的仓库目录，记录上游提交与原下载信息；小纸壳来自提供的指南与V0.3工具包，原始附件、解压文件和逆向证据另存。

原始快照保留许可证与来源。公开归档前，一处上游示例的硬编码API凭据已替换为占位符，见[脱敏记录](<机器人开发参考库/上游源码脱敏记录.json>)。研究结论、建议、静态逆向结果与实际硬件验证的范围分别标注；没有把资料下载视为真机复现。

## 下载完整资料

部分CAD、模型、媒体、固件和较大的生成文件使用Git LFS。建议先安装Git与Git LFS，再克隆：

```sh
git lfs install
git clone https://github.com/107843099/edu-robot.git
cd edu-robot
git lfs pull
```

GitHub默认ZIP通常只包含LFS指针；如某文件内容是`version https://git-lfs.github.com/spec/v1`，请用Git LFS获取实际文件。[GitHub LFS下载与归档说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/managing-git-lfs-objects-in-archives-of-your-repository)

文档链接使用相对路径，适用于GitHub和本地克隆。JSON里新转换的本机路径以仓库根目录为基准；仓库下载清单的`relative_path`仍以机器人开发参考库目录为基准。整理脚本通过自身文件位置定位资料库，避免依赖原电脑的用户目录。
