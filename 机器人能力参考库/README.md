# 机器人能力参考库

为后续机器人开发建立的表情、动作、库和调用方式索引。现有19项目资料保留在`../机器人开发参考库/`；这里把可复用部分按能力拆开，包含52张能力卡、12组预设名称、固定源码入口与版本证据，并补齐7套通用库的195个源文件。

- [按需求找能力](<需求查找表.md>)：眨眼、说话嘴巴、点头、四足/六足、停止、工具调用等。
- [按19项目对照](<项目对照表.md>)：表情、动作与源码缺口。
- [调用示例与纸壳迁移](<调用示例与移植路线.md>)：匹配环境的调用片段与提取步骤。
- [库与依赖](<库与依赖清单.md>)：版本、下载范围、许可、工具链差异。
- [预设名称](<表情动作预设清单.md>)：实际枚举、资源名、状态名和动作注册表。
- [给Codex的检索说明](<给Codex的检索与复用说明.md>)：先定位原实现，再做最薄适配。

机器入口：[能力索引](<能力索引.json>) · [依赖JSON](<库与依赖清单.json>) · [预设JSON](<表情动作预设清单.json>) · [来源和校验](<来源与校验记录.json>)。路径统一相对仓库根目录，来源记录固定上游提交、符号行、Git blob与解码文本哈希。

## 复用等级

- `original_context`：原环境可调用；新硬件需核对。
- `portable_component`：可单独提取；需接入驱动。
- `adaptation_required`：需要移植或配套运行环境。
- `reference_only`：资料或二进制边界；没有完整可调用实现。

“原环境可调用”需要相同初始化、配置、资源和硬件；不表示任意新机器人即插即用。`reference_only`材料可借外观/功能拆解，不能被Codex当作可导入SDK。普通状态调度与即时停止的区别单列I07。
