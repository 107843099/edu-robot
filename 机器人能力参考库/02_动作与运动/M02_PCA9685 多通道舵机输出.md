# M02 PCA9685 多通道舵机输出

复用等级：**可单独提取；需接入驱动**。硬件：Arduino＋PCA9685 PWM扩展板。语言：C++。

关联项目：[06 NodeHexa六足机器人](<../../%E6%9C%BA%E5%99%A8%E4%BA%BA%E5%BC%80%E5%8F%91%E5%8F%82%E8%80%83%E5%BA%93/06_NodeHexa%E5%85%AD%E8%B6%B3%E6%9C%BA%E5%99%A8%E4%BA%BA/README.md>)、[07 RookiDroid六足机器人](<../../%E6%9C%BA%E5%99%A8%E4%BA%BA%E5%BC%80%E5%8F%91%E5%8F%82%E8%80%83%E5%BA%93/07_RookiDroid%E5%85%AD%E8%B6%B3%E6%9C%BA%E5%99%A8%E4%BA%BA/README.md>)、[16 TinyEngineer桌面编程机器人](<../../%E6%9C%BA%E5%99%A8%E4%BA%BA%E5%BC%80%E5%8F%91%E5%8F%82%E8%80%83%E5%BA%93/16_TinyEngineer%E6%A1%8C%E9%9D%A2%E7%BC%96%E7%A8%8B%E6%9C%BA%E5%99%A8%E4%BA%BA/README.md>)。

检索词：PCA9685、16通道、I2C舵机、ticks、writeMicroseconds。依赖：Adafruit_PWMServoDriver、Adafruit_BusIO、Wire。

## 怎么实现

PCA9685 将多路 PWM 输出从主控移到 I2C 芯片。setPWM 通道值为 12bit 周期计数，writeMicroseconds 换算微秒。TinyEngineer 自己把角度→微秒→4096周期计数，并将 OE 和 full-off 管理封装在 ServoWrapper。

## 如何调用

创建 Adafruit_PWMServoDriver(address)，begin()，setPWMFreq(50)，再 writeMicroseconds(channel,pulseUs) 或 setPWM(channel,on,off)。4096 full-on 与 full-off 使用位置不同，Tiny 源码明确不能用 (4096,0) 表示停止。

## 移植与提取范围

在多舵机平台沿用扩展板驱动，另写每关节角度→脉宽、trim 和限位映射。纸壳只有两舵机时可比较直接 PWM 与 PCA 的接线和资源成本。

## 限制与核对点

新参考库版本与 NodeHexa 声明 ^3.0.2、Tiny 未锁版本分别记录。驱动没有自动生成步态，也不知道腿的几何；原代码的 ticks、degree、µs 不能混传。
