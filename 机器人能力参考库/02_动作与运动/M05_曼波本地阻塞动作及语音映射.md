# M05 曼波本地阻塞动作及语音映射

复用等级：**需要移植或配套运行环境**。硬件：STM32F103＋4舵机＋ASRPro串口模块。语言：C/XML。

关联项目：[02 曼波小狗](<../../%E6%9C%BA%E5%99%A8%E4%BA%BA%E5%BC%80%E5%8F%91%E5%8F%82%E8%80%83%E5%BA%93/02_%E6%9B%BC%E6%B3%A2%E5%B0%8F%E7%8B%97/README.md>)。

检索词：本地曼波、Delay、ASRPro、串口、动作字符。依赖：STM32标准外设库、Servo、Delay、ASRPro。

## 怎么实现

本地 Mode/Movement 主要通过 Servo_SetAngle 和 Delay 执行动作，串口最新字符决定模式。ASRPro 识别词在外部语音模块转换成单字节，STM32 执行对应动作；不是主控内完整语音模型。

## 如何调用

可调用 move_forward、mode_hello 等原工程函数，但模式函数还处理 OLED、LED、TTS、体力和 previous_mode。迁移时先逐项对照 voice XML 输出字符与 main 接收分支。

## 移植与提取范围

已有对照文档发现部分语音输出缺少接收动作；采用 M04 的状态机前先补全映射。只借角度顺序时应把等待改为时间戳，保留实际舵机安装方向和中心差异。

## 限制与核对点

持续行走没有可靠断线超时，且动作中长等待会延迟新命令。77 个源码文件与 GitHub 一致、23 个不同的旧对照不意味着整体等价；HEX 精确源码对应仍未证实。
