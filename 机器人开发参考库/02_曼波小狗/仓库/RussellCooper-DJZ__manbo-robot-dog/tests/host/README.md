# 非阻塞状态机主机单元测试

本目录提供一套不依赖 STM32 芯片、Keil 或实际舵机的主机单元测试。测试会直接编译仓库中的 `User/ActionTask.c` 和 `User/SafetyTask.c`，并使用测试替身模拟舵机角度、时间和 AudioTask，从而验证动作状态机的控制流。

## 运行方式

在仓库根目录执行：

```bash
./tests/host/run_tests.sh
```

也可以指定其他 C 编译器：

```bash
CC=clang ./tests/host/run_tests.sh
```

脚本使用严格警告选项编译，成功时会分别运行状态机测试、边界测试和格式化契约测试；当前结果为状态机 **32 assertions / 0 failures**、边界测试 **100 assertions / 0 failures**、格式化契约测试 **passed**。任何断言失败或编译警告都会使脚本返回非零状态。

## 覆盖范围

| 测试场景 | 验证内容 |
|---|---|
| PoseStep 推进 | 首个姿态立即执行，未到截止时间不推进，到期后推进到下一姿态。 |
| 新动作抢占 | 前进过程中切换到跳舞，新动作立即成为当前动作并应用第一步姿态。 |
| 重复命令 | 同一动作重复请求不会重置当前步骤或重新写入舵机。 |
| 急停 | 急停清除当前动作、关闭 active 标志，并将四个舵机恢复到 90° 安全姿态。 |
| 通信故障 | 通信故障被锁存，并触发动作停止和安全姿态恢复。 |
| 高级动作语音 | `B/Y/X` 动作请求可以抢占；语音请求独立于动作执行，音频忙时不会阻塞动作。 |
| ByteRing 边界 | 覆盖空队列、空指针、容量上限、满队列溢出标志、FIFO 顺序和头尾索引回绕。 |
| Timebase 边界 | 覆盖空截止时间、零周期、截止时间相等、迟到任务、`uint32_t` 回绕前后和截止时间加法回绕。 |
| 格式化安全契约 | 验证 100/30 字节缓冲区的 `vsnprintf` 截断、NUL 终止和空格式错误返回。 |

## 测试替身边界

测试替身只记录 `Servo_SetAngle1` 至 `Servo_SetAngle4` 的最后角度和写入次数，并用一个可控的简化 AudioTask 记录语音请求。测试没有模拟真实 PWM、USART2 TXE 中断、SYN6288 物理响应、TIM4 中断或运动学安全边界，因此它不能替代 Keil 目标编译、串口协议测试和实机测试。

## 后续扩展

后续可以增加环形缓冲区的满队列测试、USART 命令解析测试、AudioTask 50 字节帧校验测试、Timebase 回绕测试，以及基于硬件抽象层的集成测试。对于真实硬件，还应使用逻辑分析仪验证 SYN6288 帧间隔和急停命令到 PWM 输出变化之间的延迟。
