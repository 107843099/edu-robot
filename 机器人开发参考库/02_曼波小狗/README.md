## 已核对的硬件与能力

RussellCooper-DJZ 仓库当前为 STM32F103C8T6 与 4 路舵机，含动作、OLED 和语音子项目；Herobrine 页面列 5 个 SG90、ASR Pro 与 OLED。后者说明 HEX 功能完整，所给源码删去部分动作。

对话和控制配套现状：有语音识别和合成子工程；不能等同自由对话。

ASR Pro 语音命令 → 串口动作编号 → STM32 动作任务和姿势表 → 4 路 PWM 舵机；OLED 和语音合成按模式联动。

## 外观代码与产品思路借鉴

以下为面向后续自研与课程的分析建议。

- 程序：Russell 的动作表与任务划分可用于研究“语音命令—动作编号—目标角度与时长”的执行过程。
- 外观与集成：Herobrine 的屏幕脸、矩形身体和 PCB 布局可用于比较显示、供电与舵机怎样安排空间。
- 互动：把表情和动作组成可解释的角色状态；体力或开心值可作行为变量，不把它们当作真实情绪理解。

## 开发试验建议

选定其中一套资料，先测单舵机、动作停止与表情同步，再补传感器。若选 Herobrine 路线，把缺少的表演动作列为自行开发内容。

优先研究动作表、串口命令和角色变量。后续若加自由对话，建议沿用有限动作 ID 的边界，再接小智语音板或电脑网关；这是自研方案，并非这份 STM32 仓库已具备的功能。

## 已知限制和待补资料

Russell 旧文档的 8 舵机扩展不代表当前 4 路固件；机械资料仍需补齐。两项目的引脚、舵机数、完整源码范围都不能互换。

源码存在、说明中的功能、作者的测试和本次真机验证是不同状态。本次完成资料核查和静态阅读，未编译固件、训练模型或测试实物。
