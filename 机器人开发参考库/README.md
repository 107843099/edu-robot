# 机器人开发参考库

本库把你提供的机器人及相关配套整理成可继续开发的本地资料。[从项目总览开始](<00_%E9%A1%B9%E7%9B%AE%E6%80%BB%E8%A7%88.md>)，可直接进入17个机器人及配套技术文件夹。第15项小纸壳机器人来自本地指南与V0.3测试包，按你的倾向作为第一版实体原型的优先候选。

## 每个文件夹的内容

- README.md 是项目详细资料，包含定位、构型、外观、可借鉴点、开发试验与来源。
- 配套生态与代码导读.md 解释固件、电脑应用、语音后端、编辑器、仿真和结构之间的关系，并提供实际代码入口。
- 仓库阅读记录.md 逐一记录配套仓的角色、版本、许可和材料示例。
- 来源与版本.json 保存固定提交、下载地址、时间、文件数与原 ZIP 的 SHA256。
- 仓库目录保留原始跟踪文件快照，图片目录保留前次核验的研究配图。

小纸壳文件夹使用原始资料和工具包目录，另有第一版制作验收清单、物料接线表、逆向分析及复核证据。其来源JSON保存附件原路径、文件大小与SHA256，不虚构Git提交或公开源码仓地址。

## 下载范围

共保存76份快照，对应75个不同公开仓库。所有你原始列出的 GitHub 主仓均已获取；另追踪主 README、内部文档与作者关联项目。下载采用 GitHub 固定提交 ZIP，未下载提交历史、Releases 的所有额外资产、Issues 附件或站外视频。GitHub快照固定提交并静态阅读，新项目的部分主机检查另列，仓库自带二进制、压缩包、CAD和模型按原样保存。

第15项另保存2份附件、完整80个工具包文件与22张指南配图。小纸壳核查使用了文件与镜像校验、部分RISC-V指令解码和7项假串口组件测试；指令分析依赖安装在临时目录，原始工具保持不变。没有启动安装器、访问真实USB或烧录固件。完整嵌入式源码、原尺寸打印文件和作者自有材料的许可尚缺。

Git LFS 的81个大文件已另行实体化并按文件 OID 校验。有效子模块在[子模块核查记录](<%E5%AD%90%E6%A8%A1%E5%9D%97%E6%A0%B8%E6%9F%A5%E8%AE%B0%E5%BD%95.json>)中列出；相关 ASR 和 Dummy Peak 固定依赖另存快照，通用 SiFli SDK 等工具链不重复下载。

## 后续维护

源码快照作为研究基线保留。准备修改某个项目时，从对应 GitHub 地址建立开发仓库并固定记录中的提交，在独立开发目录修改；不要把我们的分析文档混入上游源码。升级后同时核对硬件版本、资源包、通信协议和许可证，并保留这次基线以便比较。

最近整理日期为2026-10-03 香港时间。整合建议与源码已实现的能力分别标明；新增Tiny主机测试和Needle SDK/原生离线推理已经运行，不包含固件编译、模型训练或真机测试。
