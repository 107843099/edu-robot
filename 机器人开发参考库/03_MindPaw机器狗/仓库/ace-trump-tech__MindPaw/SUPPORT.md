# Support and Troubleshooting

Use the documentation path that matches the failure:

- Firmware, Wi-Fi, sensors, or serial logs: [MindPaw_main/README.md](MindPaw_main/README.md)
- Wiring and power: [Docs/01_Hardware_Guide.md](Docs/01_Hardware_Guide.md) and [SCH&PCB/README.md](SCH%26PCB/README.md)
- PCB fabrication: [Docs/02_PCB_Fabrication.md](Docs/02_PCB_Fabrication.md)
- AI Gateway: [ai-infra/README.md](ai-infra/README.md)

Before opening an Issue, record the board, firmware commit, power voltage,
module variant, exact command, serial output, and a clear expected/actual
result. Never include API keys. Search existing Issues first.
