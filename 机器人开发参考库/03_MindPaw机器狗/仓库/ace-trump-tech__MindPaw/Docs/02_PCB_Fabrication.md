## 嘉立创免费打样

嘉立创每月提供**免费 PCB 打样**名额，适合本项目 PCB。

### 领取免费打样券

**新用户：**

1. 注册 [嘉立创下单助手](https://www.jlc.com/)
2. 下载并安装 **嘉立创下单助手**（Windows 客户端）
3. 登录后，首页通常会有 **"新用户专享免费打样"** 入口
4. 按照指引完成手机验证，即可领取 2~5 张免费打样券

**老用户：**

1. 每月 1 号嘉立创会发放 **"每月免费打样券"**
2. 登录下单助手 → **优惠券中心** → 领取当月券
3. 每月可领取 2 张：一张 PCB 免费券、一张 3D 打印券

### 下单打样步骤

1. 打开 **嘉立创下单助手**
2. 点击 **PCB/阻抗板** → **上传 Gerber**
3. 选择你在 01 指南中导出的 Gerber ZIP 文件
4. 系统自动解析后进入参数设置：

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **层数** | 2 层 | MindPaw PCB 为双层板 |
| **板材** | FR-4 | 标准玻纤板 |
| **板厚** | 1.6mm | 标准厚度 |
| **铜厚** | 1oz | 标准铜厚 |
| **阻焊颜色** | 绿色（免费） | 如需其他颜色需付费 |
| **是否拼板** | 不需要 | 单片即可 |
| **数量** | 5 片 | 免费券通常支持 5 片以内 |

5. 点击 **下一步**，在支付页面选择 **使用优惠券**
6. 确认支付 0 元（或仅需支付运费）
7. 等待 3-5 个工作日即可收到 PCB 板

### 常见问题

**Q: 为什么我的 Gerber 上传后报错？**
A: 可能是导出时选择了错误的格式。重新导出 Gerber，确保选择 **2:4 格式**、**公制单位**。

**Q: 免费打样的尺寸限制？**
A: 通常 100mm × 100mm 以内免费。MindPaw 的 PCB 尺寸远小于此限制。

**Q: 一个月只有 2 张券不够用？**
A: 多注册项目，或者选择"小批量打样"（¥5-¥20 一单，也很便宜）。

## 嘉立创 3D 打印免费券

1. 进入 [嘉立创 3D 打印](https://3d.jlc.com/)
2. 上传 3Dmodel/ 下的 STL 文件
3. 选择合适的材料（推荐 PLA）
4. 结算时使用优惠券
5. 免费券通常可打印 **2-3 个小型零件**

**建议打印顺序：**
1. 先打 `bottom.stl`（底盘，最关键）
2. 再打 `body.stl`（身体外壳）
3. 最后打 `foot.stl`（脚部 ×4）

这样即使券不够也能完成核心结构。
