## 3D 打印件组装

### 零件清单

| 打印件 | 数量 | 说明 |
|--------|------|------|
| `body.stl` | 1 | 身体主体 |
| `bottom.stl` | 1 | 底盘 |
| `foot.stl` | 4 | 脚部 (每条腿一个) |

### 组装步骤

**Step 1：底盘安装**
1. 将 `bottom.stl` 平放
2. 安装 4 个舵机到底盘预留的槽位中
3. 用螺丝固定（推荐 M2 螺丝）

**Step 2：身体合体**
1. 将 `body.stl` 对准底盘
2. 从底部用螺丝将两者固定
3. 走线从身体内部的空腔穿过

**Step 3：安装脚部**
1. 将 4 个 `foot.stl` 分别安装到舵机摇臂上
2. 调整到初始角度（90度）

## 各模块接线详解

### 舵机 ×4

| 舵机 | ESP12F | 伺服线 (橙/红/棕) |
|------|--------|------------------|
| Servo 1 | GPIO14 (D5) — 信号 | 橙 ← GPIO14, 红 ← 5V, 棕 ← GND |
| Servo 2 | GPIO16 (D0) — 信号 | 橙 ← GPIO16, 红 ← 5V, 棕 ← GND |
| Servo 3 | GPIO12 (D6) — 信号 | 橙 ← GPIO12, 红 ← 5V, 棕 ← GND |
| Servo 4 | GPIO13 (D7) — 信号 | 橙 ← GPIO13, 红 ← 5V, 棕 ← GND |

> ⚠ 所有舵机红线接 **5V 电池直供**（不要接 ESP 的 3.3V！）

### OLED 显示屏 (SSD1306, I2C)

| OLED 引脚 | 接 ESP12F |
|-----------|----------|
| GND | GND |
| VCC | 3.3V |
| SCL (时钟) | GPIO5 (D1) — 4.7KΩ 上拉 |
| SDA (数据) | GPIO4 (D2) — 4.7KΩ 上拉 |

### OV2640 摄像头 (ArduCAM Mini, SPI)

| OV2640 引脚 | 接 ESP12F |
|-------------|----------|
| CS | GPIO15 (D8) — **10KΩ 下拉到 GND** |
| SCK | → 1KΩ → GPIO14 (D5) — 与 Servo 1 共享 |
| MISO | → 1KΩ → GPIO12 (D6) — 与 Servo 3 共享 |
| MOSI | → 1KΩ → GPIO13 (D7) — 与 Servo 4 共享 |
| VCC | 3.3V |
| GND | GND |

### HLK-V20 语音模块 (UART)

| HLK-V20 引脚 | 接 ESP12F |
|-------------|----------|
| TX | GPIO0 (D3) — SoftwareSerial RX |
| RX | **悬空**（仅在 PC 配置时用 USB-TTL） |
| VCC | 3.3V ~ 5V |
| GND | GND |

### 扬声器 (三极管驱动)

```
                    +5V
                     │
                    ╱
                  ╱ 喇叭 (8Ω/0.5W)
                  ╲
                    │
                    │  C
GPIO16 ──[1KΩ]───── B  NPN (S8050/2N2222)
                      E
                      │
                     GND
```

### 供电方案

MindPaw 支持两种供电方式：

#### 方案 A：USB 供电（推荐，¥0）

**这是最省钱的方式**，直接用手机充电器 + MicroUSB 线：

```
手机充电器 (5V/1A+) ── MicroUSB 线 ── ESP12F 开发板 USB 口
                                    │
                                AMS1117 稳压到 3.3V
                                    │
                            ┌───────┴───────┐
                            │               │
                         舵机 5V          OLED/OV2640/HLK-V20 3.3V
```

| 要求 | 说明 |
|------|------|
| 充电器 | 5V / 1A 以上的手机充电器（任何 Android 充电头都行） |
| 数据线 | 普通 MicroUSB 线（注意：要能传数据的，不是纯充电线） |
| 舵机供电 | 开发板 USB 口的 5V 会直接供给舵机（红线） |

> ⚠ **SG90 舵机堵转时电流 ~700mA**，4 个同时动作峰值约 2.8A。
> 建议用 **5V/2A 以上的充电器**。如果舵机卡顿，试试更大电流的充电器。
> 正常行走时平均电流 ~500mA，普通手机充电器完全够用。

#### 方案 B：电池供电（可选，¥30+）

需要移动使用（不插线）时，加 2S 锂电池：

| 模块 | 供电 | 电压 |
|------|------|------|
| ESP12F | 通过 AMS1117 稳压 | 3.3V |
| 舵机 ×4 | 电池直供 | 5V ~ 8.4V |
| OLED | ESP12F 3.3V 输出 | 3.3V |
| OV2640 | ESP12F 3.3V 输出 | 3.3V |
| HLK-V20 | ESP12F 3.3V 输出 | 3.3V~5V |

**电池分压电路 (ADC 检测)：**
```
电池+ (8.4V max) ── R1 (100KΩ) ──┬── A0 (ESP12F)
                                  │
                              R2 (12KΩ)
                                  │
                                 GND
```

> 💡 **省钱建议**：先用品茗座或 USB 供电开发调试，全部调通后再决定要不要加电池。

## ⚠ 关键注意事项

### 启动必需条件

| 引脚 | 启动状态 | 如果不满足 |
|------|---------|-----------|
| GPIO0 | 必须 **HIGH**（或浮空） | 模块进入下载模式 |
| GPIO15 | 必须 **10KΩ 下拉到 GND** | **模块无法启动** |
| GPIO2 | 必须 **HIGH**（内部上拉） | 串口初始化异常 |

### 调试技巧

1. **首次上电**：先只接 ESP12F + USB-TTL，确认串口能输出日志
2. **舵机不动**：检查 5V 供电是否正常，舵机信号线是否接对
3. **OLED 不亮**：检查 I2C 上拉电阻（4.7KΩ）、确认地址是 0x3C
4. **HLK-V20 无反应**：用 USB-TTL 连模块，确认配置已烧录
5. **OV2640 不工作**：检查 GPIO15 下拉电阻、检查 SPI 共享的 1KΩ
