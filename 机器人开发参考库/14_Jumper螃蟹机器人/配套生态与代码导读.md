## 从输入到机器人行为

训练任务 → PyTorch 与 ONNX 导出及 layout.json → RKNN 转换 → Rust FSM 和 DDS → 关节；外观和场景由 jumper-design 打包。

## 配套关系与实现判断

Jumper 主仓围绕22自由度螃蟹、任务训练与部署，jumper-design 提供外观.skin和场景.map，训练与控制器组合为.app。三个内容类型可分别用于机械外观、虚拟环境与动作课程，不宜把生成皮肤文件当作可直接制造的结构改造。

主仓 tasks 包括步态、姿势、手势、舞蹈、跳跃与夹爪任务。训练模型经 scripts/export.py 导出 ONNX 和 layout.json，后者携带关节名、观测顺序、尺度、限制和控制频率；部署用 Rust FSM，按名字把策略关节对应到22关节总线。部分步态只驱动20关节，夹指在总线索引4和9，按数组下标硬拼会从中段开始错位。

参考动作还要带 trajectory.json，缺少就拒绝装包。RKNN 转换与 DDS IDL 是部署配套，源码说明仍未在真板验证 rknn_run 和完整总线控制环；1kHz 发布属于设计目标，不写成实测成果。双屏、音频、摄像头等属于硬件规格，当前下载代码不等于完成全套 AI 陪伴功能。

jumper-design 的81个 Git LFS 大文件已补成实际内容并按 OID 与大小校验，下载记录在本文件夹。其皮肤和地图有来源记录及独立第三方条款；新模型自动通过格式检查，不代表机械间隙、强度和物理适配已验证。

通用 mjlab、rsl_rl、MuJoCo、Warp、RKNN 和 CycloneDDS 是训练/构建依赖，已在依赖清单给出来源，不把整套工具链重复搬进机器人快照。

## 后续开发接入建议

先研究纯仿真任务和布局契约，做一个表情/动作或地图作品。真机复现另列板上 RKNN、DDS 版本和控制环验收；不要从演示视频直接推断当前下载控制器已能稳定驱动硬件。
