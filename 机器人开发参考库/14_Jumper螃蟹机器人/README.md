# Jumper 螃蟹机器人 详细资料

螃蟹形态、钳形前肢和动作任务库适合研究多关节角色。当前最有参考价值的是仿真、策略和部署的组织方法，真机成熟度需单独判断。

## 已核对的硬件与能力

官方规格列 22 自由度与 RK3576 等硬件；本次确认仓库包含仿真模型、动作任务、训练／回放／导出脚本和 Rust 运行状态机。不能仅凭 mesh 文件认定完整制造 CAD、PCB 已开放。

对话和控制配套现状：训练、外观、场景与部署配套明确；本快照的控制器仍有真机验证缺口。

训练任务 → PyTorch 与 ONNX 导出及 layout.json → RKNN 转换 → Rust FSM 和 DDS → 关节；外观和场景由 jumper-design 打包。

## 外观代码与产品思路借鉴

以下为面向后续自研与课程的分析建议。

- 动作内容：将行走、跳跃、舞蹈和手势按任务组织，便于独立研究和比较训练结果。
- 平台：把控制策略、输入映射与内容包分开，可用于设想后续可下载任务的教学机器人。
- 研发流程：明确记录仿真完成、板上推理和真实电机控制的不同状态，为进阶项目设定可验证目标。

## 开发试验建议

先在仿真中跑一个动作任务，阅读观测量与动作定义；确认硬件部署条件后再安排真实电机实验。

先研究纯仿真任务和布局契约，做一个表情/动作或地图作品。真机复现另列板上 RKNN、DDS 版本和控制环验收；不要从演示视频直接推断当前下载控制器已能稳定驱动硬件。

## 已知限制和待补资料

官方指南明确 RKNN 板上推理和 1 kHz 真机电机总线尚未验证。图中是仿真渲染，不能作为整机已完成端到端实测的证据。

源码存在、说明中的功能、作者的测试和本次真机验证是不同状态。本次完成资料核查和静态阅读，未编译固件、训练模型或测试实物。
