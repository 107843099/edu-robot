## 从输入到机器人行为

电脑 ElectronStudio 或应用 → USB SDK → STM32 主板 → 自定义反馈舵机和圆屏；语音扩展另提供 USB 音频硬件。

## 配套关系与实现判断

ElectronBot 主仓内已含主板和舵机固件、低层 SDK、Player、UnityBridge、ElectronStudio、测试与 CAD。应按“USB 最小测试 → 低层数据 → 播放器 → 动画编辑器”读，理解屏幕帧与关节角怎样同步。

主 README 指向第三方 ElectronBot-Voice。其推荐版本一更换传感板，使电脑识别为 USB 声卡和麦克风，原主板保持；版本二把主板 SD 模块换成 WM8978，主要用于音频底层学习。README 说 SDK demo 仍在路上，不能把它当作已经完成的大模型聊天软件。真正对话还需电脑应用或语音后端。

ElectronBot-Peripheral 提供装饰、背包、精英壳和语音壳的扩展模型，README 明确部分未验证。该仓没有根 LICENSE，模型授权和机械适配逐个确认。它也被 Otto 教程引用，资料复用通过本库链接完成。

同作者 Dummy-Robot 展示机械臂、CAN/驱动和上位机系统，CycloidAcuratorNano 是微型减速器结构，Peak 是嵌入式屏幕 UI 参考；友人的 XDrive 则是相关步进驱动。它们提供机械和软件分层思路，不是 ElectronBot 的必装配套。Dummy 的 Peak 子模块固定 c7a90eda，本库同时保留当前 Peak 与这个固定快照，避免用最新版误当原始依赖。

原始工程有较大的依赖压缩包，本库保存了仓库中的压缩文件，但未安装或自动解压到编译工程。Windows 驱动、SDK 构建、定制舵机和装配公差仍要单独验证。

## 后续开发接入建议

先学习进入、循环、退出三段表情与动作编排接口；反馈舵机和 USB 音频作为高阶专题。新增对话先从电脑端串接，不把语音扩展板的存在当作自由问答实现。

这些为开发建议，本次没有声称完成硬件复现或跨仓兼容性验证。
