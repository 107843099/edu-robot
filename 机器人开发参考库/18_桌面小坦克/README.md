# 桌面小坦克

这是一套ESP32-S3、TB6612FNG双电机、浏览器操纵及轨迹编排的桌面履带底盘资料。独立建为第18项：它与曼波四足的机构和驱动不同，又能为后续机器人补充移动底盘、网页控制、配网和停止机制的参考。

## 控制能力与限制

源码默认20kHz、10bit PWM，左右电机分开设置方向与速度；浏览器经/ws发送驱动命令，NVS保存WiFi、左右反向和交换、轨迹数据。轨迹的计时和循环在浏览器执行，设备保存的路径不是独立导航控制器；断开浏览器不会继续自动跑完整路线。

提供的sdkconfig将命令超时设为500ms，设备watchdog每100ms检查一次并调用停止。它有应用层停机保护，但不是已经实测的精确500ms机械刹车。当前为HTTP且未见控制鉴权；启动配网时还存在不同工作模式。应先在受控局域网复核通信和停止。

主机复核证明控制算法的85%限幅在加8%死区后会到93%。速度坡度按每次调用增加8%，调用频率改变会影响加速。整机没有在本次资料中给出编码器、里程计或测距闭环，因此轨迹时长不等于真实距离。

## 研发与教学借鉴

适合在纸壳首版稳定之后研究底盘模块，把外观角色和运动驱动分开。课堂可让学生比较左右速度与转弯关系，记录不同地面和电量下的路线偏差，再提出加入编码器的方案。先用手动网页控制验证方向、停止和配网，再考虑接入小智或有限意图解析；原工程没有给出对话集成。

代码、3MF和PCB缺少整体明确许可证。managed_components里的mdns第三方许可不能覆盖作者自有代码和结构。BOM金额为原表参考记录，未注明统一币种口径，也不是当前香港采购报价。
