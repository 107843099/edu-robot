## 已核对的硬件与能力

README 提供 ESP32 C3／S3 Supermini 路线、1.28 英寸屏幕和音频组件，未列舵机。发布仓主要为 bin、docs；可编译源码在作者小智仓库的 emo-dot 分支，外壳及 PCB 另有来源。

对话和控制配套现状：已有独立固件分支；原资料仓主要提供说明与固件二进制。

圆屏设备的麦克风与音频板 → 作者 emo-dot 小智固件 → 网络语音服务 → 喇叭和表情；脚形外壳不包含步行机构。

## 外观代码与产品思路借鉴

以下为面向后续自研与课程的分析建议。

- 外观：让屏幕轮廓成为脸部的一部分，结合比例和固定脚座形成角色，不必先增加机械复杂度。
- 装配：研究卡扣与少紧固件设计，减少课堂装配步骤；在新壳体中保留拆装与检修空间。
- 产品配置：对照 C3 与 S3 两套配置，研究基础互动与语音唤醒需求如何影响主控选择。

## 开发试验建议

在一套选定的屏幕与音频硬件上验证表情、触摸和语音，重新画自己的外壳；记录配网、烧录和装配用时。

先选 C3 触摸版或 S3 唤醒版，核对 Flash、PSRAM 与分区后烧录；后续原创外壳和表情，先建立语音、聆听、思考、播音几个清楚可见的角色状态。

## 已知限制和待补资料

脚形外壳不代表具有行走能力。作者历史价格未包括本项目全部采购、打印、装配与返修费用；固件分区和板型需严格匹配。

源码存在、说明中的功能、作者的测试和本次真机验证是不同状态。本次完成资料核查和静态阅读，未编译固件、训练模型或测试实物。
