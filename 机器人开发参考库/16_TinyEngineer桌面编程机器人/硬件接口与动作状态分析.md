# 硬件接口、动作状态与逆向阅读

本节分析公开源码的行为，不涉及刷写固件或操作真实舵机。结论基于固定提交的pins.h、servos.h、HTTP handlers和animation controller。

## 接线与纸壳第一版的差异

| 功能 | Tiny Engineer | 小纸壳V0.3指南基线 |
|---|---|---|
| 头部与其他关节 | PCA9685通道0–4，5个舵机 | GPIO5/6直接驱动双轴SG90 |
| 显示 | 128×32 OLED | 128×64 OLED |
| I2C | SDA0、SCL1；PCA0x40、OLED0x3C | 以纸壳物料接线表及实际板卡确认 |
| 音频 | BCLK2、WS3、DOUT4，MAX98357A | 首版模块包不等同于该I2S链路 |
| 输入 | 主机HTTP事件 | 摸头GPIO10，红外GPIO4/3 |
| GPIO5 | PCA OE预留，默认`PCA9685_OE_WIRED=false` | 已作舵机输出 |
| GPIO10 | 板载RGB | 摸头输入 |

证据：[Tiny引脚表](<仓库/jamro__tiny-engineer/docs/hardware/pinout.md>)、[纸壳接线分析](<../15_小纸壳机器人/物料接线与机构拆解.md>)。直接烧入Tiny固件会产生引脚、屏幕和执行器驱动冲突，复用应从状态和动作表达开始，逐项重写硬件适配。

## 舵机控制的数学关系

代码先将归一化动作值 `n` 限制在[-1,1]，再映射为：

`angle = (min + max)/2 + n × (max - min)/2`

当前默认范围为头60–130°、颈40–130°、左手45–135°、右手35–125°、躯干40–130°。这些范围只对应Tiny原结构。全局速度上限140°/s、校准25°/s、死区0.32°、PWM角度步长0.63°、停止后释放延迟2秒，均来自[servos.h](<仓库/jamro__tiny-engineer/include/servos.h>)。实际SG90偏差、回差和纸板摩擦仍需测量。

[servo_wrapper.cpp](<仓库/jamro__tiny-engineer/src/hardware/servo_wrapper.cpp>)同时处理电气范围和校准范围，按时钟插值到目标。借鉴点是“角色坐标→各机型范围→限速输出”，不是复用某一组角度。纸壳支架较软，首版宜只迁移head/neck概念，小幅低速运动再增加动作幅度。

## HTTP控制语义

[API文档](<仓库/jamro__tiny-engineer/docs/api.md>)与路由实现须共同阅读。Wi-Fi连接后通过HTTP80访问，支持mDNS；配网热点地址为192.168.4.1。动画请求形式为 `POST /anim?name=thinking`，不是随意发送`{"angle":90}`。

动作名缺失或不合法返回400；部分未就绪状态返回503；令牌启用时需要Bearer认证。`access_token`默认空，接口可处于无认证状态；公开网页、认证状态查询和CORS行为不应理解为完整权限系统。GET健康状态适合调试，配置类接口有配网模式限制。课堂整合建议明确设备编号、令牌、任务ID和请求来源；不能把“在局域网”当作同一学生设备。

## 状态切换为何不等于急停

[controller.cpp](<仓库/jamro__tiny-engineer/src/animation/controller.cpp>)要求动画至少保持1秒。时间未到时，新动作写入一个pending槽，后续请求可替换它；到时再应用。重复请求同一个持续状态会清掉pending并刷新持续状态时钟，不重启动作。

默认持续超时为5分钟，超时转attention，不是立即停机。`abort`也走常规切换路径，可能等待保持时间；none先停放，再等舵机稳定后释放PWM。OE线默认未接，不能假定有软件可用的硬件断使能。由此得到的迁移建议是：独立的急停通道应绕过动画保持，设备端实现短时断线看门狗，并按实物结构决定停PWM、停放还是切断舵机电源。本次未实现该通道，也没有验证断电后的姿态安全。

## 可复现验证与缺口

[主机验证记录](<分析证据/主机验证记录.json>)记录真实命令与结果；Node3包28项、Python9项通过，480帧像素一致。没有执行PIO native、完整固件编译、expression-demo板卡演示和KiCad10检查，原因是本次采用现有Node/Python主机环境进行资料验证，没有配置这些工具链。

PlatformIO配置使用上游stable地址与部分未固定依赖，固定源码提交并不等于固定了所有构建输入。正式移植前须记录工具链版本、解析后的依赖、屏幕/舵机型号与结构尺寸，并在真实电源条件下完成开机、复位、断线和机械限位验收。
