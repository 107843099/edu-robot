# Tiny Engineer：把编程过程变成桌面机器人的动作

**研发判断：优先借鉴它的角色表现、动作状态表、校准和主机事件接口。** 它适合成为课程桌面的“学习搭档”，也适合启发纸壳机器人的第二阶段表达设计。模型与编程助手在电脑端工作，ESP32-C3接收状态并驱动身体；没有证据表明它在机器人内运行编程大模型或完整语音对话。

主仓固定提交 `d71eb42a7abd98d81aae17472f35ba9d55ef5c89`，2026-10-03核查。已下载主仓和同作者3个相关项目，共4份快照、1,125个文件，保留CAD、打印件、PCB、固件、资源和主机集成。

![作者项目预览](<仓库/jamro__tiny-engineer/docs/tiny-engineer-preview.jpg>)

图片来自上游：机器人坐在小桌后，矩形屏幕眼睛、双臂、灯和铃形成“正在工作的工程师”角色。可借鉴的是场景道具如何解释行为；用于自己的课程产品时应创作自己的角色、外观和名称。

## 项目能力与设备分工

| 部分 | 当前可核对的实现 | 对我们的价值 |
|---|---|---|
| 电脑上的编程助手 | Cursor、Antigravity、Claude Code钩子将事件映射为动作名 | 学生平台的运行、等待、完成、错误反馈 |
| ESP32-C3固件 | Wi-Fi HTTP、NVS配置、动画控制、OLED、RGB、I2S音效 | 用同一状态协调表情、头部和声音 |
| 身体 | 5个SG90，通过PCA9685控制头俯仰、颈偏航、双臂和躯干 | 少关节表达情绪，结构校准与动作限幅 |
| 外观与制造 | Fusion源CAD、3MF打印件、装配图、可选MOD和KiCad板 | 结构拆分、可装配性、主题换装 |
| 对话 | 主仓没有完整麦克风→ASR→对话→TTS链路 | 同作者YOVA是独立语音系统，可研究适配 |

证据入口：[上游README](<仓库/jamro__tiny-engineer/README.md>)、[主程序](<仓库/jamro__tiny-engineer/src/main.cpp>)、[引脚表](<仓库/jamro__tiny-engineer/docs/hardware/pinout.md>)。主仓现成三种钩子均在 `packages/` 内；未发现现成Codex专用包。通用HTTP适配属于后续开发建议。

## 物料、供电和装配边界

基本部件包括ESP32-C3-Zero、PCA9685、128×32 I2C OLED、MAX98357A与扬声器、5个SG90、USB供电和打印结构。上游README给出约50–70美元零件估算；这是作者估算，未重新核价，也不包括我们在香港的采购、打印、工时和课程消耗。

舵机使用5V供电，逻辑使用3.3V，两者共地；应按上游供电指南核对电源与线材，不把多舵机电流压到开发板3.3V稳压器上。实际堵转峰值、压降、温升和结构碰撞没有在本次研究中实测。先做纸壳双轴版，再决定是否增加手臂、躯干、铃和扬声器，可减少首版装配与校准变量。

## 最值得迁移的设计

1. **动作名表达用途。** `reading / thinking / typing / ring / error / attention` 可以映射为阅读任务、等待计算、运行程序、完成、错误和请求帮助。用同一“学习状态”驱动多个输出，避免表情和身体互相矛盾。
2. **角色表达与机械参数分开。** 归一化动作坐标映射到各关节校准范围，速度受限；换纸壳结构时重新测范围，动作意图仍可复用。
3. **内容与程序分开。** WAV、眼睛样式、主题MOD与控制程序分目录，方便学生设计角色并比较同一动作的不同表达。
4. **调试作为产品能力。** 配网、健康状态、校准页面、参数检查和资源校验降低复刻门槛。我们应在第一版保留可见的校准和验收过程。

重要边界：动作切换有最短保持时间；`abort`是表现状态；OE硬件线默认未接。以上都不能替代我们的急停、断线超时和真实动作回执。详见[接口与状态分析](<硬件接口与动作状态分析.md>)。

## 配套作者项目与许可

已阅读并下载YOVA语音助手、Desk HUD桌面面板、Brass Thumb机械番茄钟。它们是独立项目，没有确认到可直接插上Tiny Engineer的适配器。YOVA默认配置使用云端转录和TTS、英语提示，不能写成“整套完全离线中文对话”。完整配套关系见[代码导读](<配套生态与代码导读.md>)与[逐仓阅读记录](<仓库阅读记录.md>)。

主仓软件为MIT；机械CAD、制造输出和PCB为CERN-OHL-S-2.0，修改并分发产品时具有对应完整源文件的互惠要求。项目名称和标志另有商标声明。必须按路径核对：[LICENSING.md](<仓库/jamro__tiny-engineer/LICENSING.md>)、[REUSE.toml](<仓库/jamro__tiny-engineer/REUSE.toml>)、[TRADEMARK.md](<仓库/jamro__tiny-engineer/TRADEMARK.md>)。其他3个快照各自带MIT许可，不能因此替主仓硬件改成MIT。

## 本次验证和后续入口

已通过28项Node事件/环境映射测试、9项音频资源打包测试，以及16种表情480帧的生成一致性与像素打包检查。源码逐文件与固定提交ZIP比对一致。没有运行固件烧录、KiCad ERC/DRC或真实机器人测试；主机测试通过不代表五舵机系统已经复刻。
