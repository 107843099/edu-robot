# NodeHexa 六足机器人 详细资料

中央机身、模块化六腿与可视化控制适合做进阶运动学平台。对我们的价值主要是从单腿校准逐步扩展到整机的工程流程。

## 已核对的硬件与能力

ESP32 NodeMCU-32S 与 PCA9685，六腿各三关节；有机械、六足 PCB、固件和网页资料。同仓还含 NodeQuadMini 四足子项目，其 PCB 未公开。

对话和控制配套现状：有 UART 扩展和小智关联；语音服务不是六足芯片内的大模型。

Web 或扩展 UART 指令 → 通用 Robot 接口 → 六足或四足运动学、动作和校准 → 舵机输出；小智可作为独立语音扩展。

## 外观代码与产品思路借鉴

以下为面向后续自研与课程的分析建议。

- 结构：将单腿作为可重复装配、调试和替换的模块；先保存连杆尺寸和零位，再组合整机。
- 程序：构型接口、运动、动作序列、通信与电源管理分开组织，便于在不同机型间保留公共逻辑。
- 教学工具：逐关节校准、参数保存与足端实验，可对应“单舵机—单腿—步态—指令控制”的进阶课程。

## 开发试验建议

先搭一条腿，验证方向、中位、范围与足端轨迹；再增加其余腿，记录供电与校准工作量。

先做单腿、校准保存和停止，再选六足或四足整机。语音板独立验证串口动作返回，最后联动；记录关节顺序、尺寸与零位，防止把不同构型的参数混合。

## 已知限制和待补资料

装配和线束量明显增加；可选图传与小智扩展不是所有版本的默认能力。README 中超声波用于按需诊断，不应写成已接入自主运动决策。

源码存在、说明中的功能、作者的测试和本次真机验证是不同状态。本次完成资料核查和静态阅读，未编译固件、训练模型或测试实物。
