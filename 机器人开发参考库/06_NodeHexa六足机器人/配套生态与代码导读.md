## 从输入到机器人行为

Web 或扩展 UART 指令 → 通用 Robot 接口 → 六足或四足运动学、动作和校准 → 舵机输出；小智可作为独立语音扩展。

## 配套关系与实现判断

NodeHexa 同仓包含六足和 NodeQuadMini 四足；两者共用 Web 控制、校准、动作管理及电源策略。机械尺寸和构型实现分开，是后续多种造型共用软件的好参考。硬件目录说明四足 PCB 尚未公开，不能把四足也写成完全齐套。

小智扩展应沿 uart_protocol、external_device 和实际接线理解：先让外部语音板得到结构化动作意图，再发送设备协议，由运动控制器执行。本库已有小智官方、多个设备分支与后端，统一放在 08 文件夹并从这里链接，不重复复制整套软件。

PiHexa18 是同作者的树莓派 Python 前序，带真实运行和电脑 Matplotlib 动画；NodeHexa 和 PiHexa 又都引用 SmallpTsai 的 hexapod-v2-7697 运动学上游。三者值得比较参数、坐标约定和步态表达，但不能直接互换供电和引脚。

对我们最有价值的是从单腿足端实验到多腿编排，再到语音指令的课程层次。超声波当前以按需诊断为主，不应宣传为已形成自主避障。GPL 声明与缺少完整根许可文件仍分别记录。

## 后续开发接入建议

先做单腿、校准保存和停止，再选六足或四足整机。语音板独立验证串口动作返回，最后联动；记录关节顺序、尺寸与零位，防止把不同构型的参数混合。

这些为开发建议，本次没有声称完成硬件复现或跨仓兼容性验证。
