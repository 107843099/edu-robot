## 已核对的硬件与能力

ESP32-S3，4 舵机基础动作、增加双臂为 6 舵机；文档含材料、装配、烧录和调试。设备源码另在 txp666/xiaozhi-esp32 的 otto-robot 板级目录。

对话和控制配套现状：文档、设备固件、表情组件、网页调试与早期动作库都有配套。

小智语音与 MCP → self.otto.action 等工具 → OttoController 动作调度 → 周期运动和舵机；表情组件和网页调试独立配合。

## 外观代码与产品思路借鉴

以下为面向后续自研与课程的分析建议。

- 动作：以周期、幅度和相位组织舞蹈与摆动，可转成参数变化的数学和编程实验。
- 工具：网页烧录、舵机微调与动作调试，可减少教师重复安装工具和逐台配置的工作。
- 课程：按语音意图、工具参数、动作队列与执行器分层，让学生解释命令怎样变成真实动作。

## 开发试验建议

先做中位校准和一个摆动，再加入表情及语音指令；将装配步骤与可修改参数整理成教师任务卡。

把“舵机中位校准 → 周期和幅度 → 一个舞步 → 语音工具调用”做成递进任务。动作停止、中途打断与低电量行为先验证，再扩展多动作编排。

## 已知限制和待补资料

文档与当前固件的 MCP 工具名称有差异，必须固定版本。双足动作受装配、摩擦和电源影响；shanmaotech.cn 本次未能稳定访问，关联由项目站链接确认。

源码存在、说明中的功能、作者的测试和本次真机验证是不同状态。本次完成资料核查和静态阅读，未编译固件、训练模型或测试实物。
