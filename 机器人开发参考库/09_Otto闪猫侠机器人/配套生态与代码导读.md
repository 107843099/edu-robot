## 从输入到机器人行为

小智语音与 MCP → self.otto.action 等工具 → OttoController 动作调度 → 周期运动和舵机；表情组件和网页调试独立配合。

## 配套关系与实现判断

ottodiy-docs 是 Docusaurus 教程及网页工具，真正运行在设备的源码在 txp666/xiaozhi-esp32 的 otto-robot 板级目录。文档、固件与 otto-emoji-gif-component 三者一起读，才看得出语音、表情和动作怎样组成教学产品。

当前 OttoController 注册 self.otto.action、servo_sequences、stop、set_trim、get_trims、get_status 等工具。动作参数由周期、幅度、步数等形成具体执行；网页调试与 MCP 最终应落到同一控制器，避免两条链路各自写舵机。旧文档工具名称可能与当前统一 action 不同，以本次快照源码为准。

OTTO_ESP32 是同作者的早期蓝牙和屏幕路线，README 已声明弃用、建议转小智版；保存它用于理解动作库和机械演变，不推荐作为新系统主线。原始 OttoDIYLib 是运动算法上游，重点读周期振荡和相位，GPL 与 CC BY-SA 的声明要按文件和材料范围分别理解。

文档的 Peak 与 ElectronBot-Peripheral 链接是显示、机械和外设参考，已经下载到 ElectronBot 文件夹，跨目录链接。它们并不构成 Otto 必须装配的全部硬件。4 舵机与6舵机版本要在机构、固件参数和壳体上保持一致。

## 后续开发接入建议

把“舵机中位校准 → 周期和幅度 → 一个舞步 → 语音工具调用”做成递进任务。动作停止、中途打断与低电量行为先验证，再扩展多动作编排。

这些为开发建议，本次没有声称完成硬件复现或跨仓兼容性验证。
