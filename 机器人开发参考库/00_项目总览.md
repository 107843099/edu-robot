# 机器人开发参考总览

这份总览用于选择后续开发方向，并定位每个机器人的外观、硬件、源码与配套生态。已将你列出的 GitHub 主仓及相关配套保存为本地快照，并加入你提供的小纸壳机器人指南与V0.3工具包，按19个机器人及配套技术项目分文件夹；重复的 Stack-chan 合并，曼波的两个来源分开解释。

最新核查日期为2026-10-03 香港时间。本库保存 76 份快照，对应 75 个不同 GitHub 仓库；Peak 的当前版本和 Dummy 固定依赖各保存一份。共用小智后端、客户端和资源工具通过跨文件夹链接复用。源码是固定提交的跟踪文件快照，不含 Git 历史；下载、静态阅读和主机试验不代表真机复现。

小纸壳另存2份本地附件、80个工具包文件和22张指南配图，不计入GitHub快照数。它按你的最新倾向列为第一版实体原型的优先候选；当前包只有网页源码与已编译固件，完整嵌入式源码和整体许可仍待确认。

## 怎样使用这些资料

先看项目 README 的硬件范围、外观和可借鉴点，再读配套生态与代码导读确认功能在哪一块设备运行。最后按逐仓阅读记录打开原始文件。GitHub项目的来源与版本 JSON 给出原地址、分支、完整提交和下载时间；小纸壳的记录保存本地附件原路径及哈希，便于以后固定研发基线。

芝麻的对话 Companion、小豆的 emo-dot 分支、Otto 的设备固件、Verdure Rover 的专用语音分支，以及 XGO-Duck 的运行与训练配套已纳入主要说明。语音命令、自由对话、模型研究、硬件扩展是不同能力，表格按当前可核对的链路分别填写。

本次研究重点是外观结构、接口、角色行为、动作编排、开发工具和配套关系。价格、性能、寿命、量产和跨仓兼容仍需要我们自己的采购与实物试验。

## 新增本地材料的整合

曼波本地包并入第02项，保留其与GitHub任务版本、立创五舵机方案的区别。第18项是新移动底盘，第19项是多款固件及配套技术档案。GitHub快照仍为76份/75仓；本地来源不计入GitHub数。新增材料收到9个原文件，公开8份原文件及768个解压文件，略懂BIN因有效私钥仅本地保存，天问大型安装器完整留在曼波原ZIP中。

[曼波版本对照](<02_曼波小狗/本地资料对照与迁移分析.md>)记录语音输出与case、HEX及无超时保持命令；[坦克协议](<18_桌面小坦克/控制协议与失联保护分析.md>)记录浏览器计时和500ms设备阈值；[作者版本边界](<19_每逢佳节瘦三斤固件生态/固件版本与接线边界.md>)记录唤醒/动画取舍和源码接线缺口。原始BIN商业限制、私钥处理和检查范围均单独记录。
