# 小纸壳机器人第一版制作与验收清单

目标是完成一台可重复上电、表情清楚、左右输入对应、能回应摸头、双轴无明显干涉的纸板桌面机器人。你尚未最终确定方案，本清单按“优先候选”准备。以下均为待执行验收，不表示实物已经通过。

制作前读[接线和供电表](<%E7%89%A9%E6%96%99%E6%8E%A5%E7%BA%BF%E4%B8%8E%E6%9C%BA%E6%9E%84%E6%8B%86%E8%A7%A3.md>)；开发前读[逆向与迁移分析](<%E9%80%86%E5%90%91%E5%88%86%E6%9E%90%E4%B8%8E%E8%87%AA%E7%A0%94%E8%BF%81%E7%A7%BB%E6%96%B9%E6%A1%88.md>)。

## 开工前要具备的条件

- [ ] 确认ESP32-C3板型、OLED驱动与尺寸、两只位置式SG90、数字红外及TTP223工作模式。
- [ ] 备好数据USB线，测量并标明电源模块的3.3V、5V、VIN和GND。
- [ ] 确认A4模板单位、比例和纸厚；先做纸样与实物试配，保留折线和粘接耳。
- [ ] 保留完整工具包目录，记录V0.3与原ZIP哈希；有旧校准时先抄录数值。
- [ ] 确认可用的刷写电脑和浏览器。Windows启动脚本由作者提供；Mac路线仍需验证。
- [ ] 第一台先用配套适配器与电源模块，电池和语音作为后续独立实验。

模板、主控USB路径和稳定供电是目前三个关键开工缺口；可以先做物料比对与纸样，不凭未确认条件直接完成永久装配。

## 每个步骤重复的操作

1. USB和全部外部电源均断开后接线；OLED SDA接GPIO0、SCL接GPIO1，GPIO8/9空闲。
2. 下载时外围外部电源关闭，主控仅接电脑USB，外部5V线不接主控5V脚。
3. 按住BOOT，按下RST，松开RST，再松开BOOT，等端口重新出现；安装对应步骤固件。
4. 关闭安装对话框，按当前步骤恢复外围供电，按RST进入应用，再连接测试串口。
5. 分别验收固件身份、OLED实物画面及模块动作；界面预览与“匹配”提示不能替代观察。
6. 写下结果、异常和版本。换到下一步前再次断开USB及外部电源。

安装器可能整片擦除；六项是六个不同应用，每换一步都可能改写程序。下载模式中不能验收应用功能。界面开到后台或关闭完整系统串口也不能当作急停。

## 装配和校准

- [ ] 切割后先干装，确认显示窗、左右红外开口、底座隔板与接头通道。
- [ ] 给主控、电源板及两根舵机线贴标签；隔离裸露金属，预留USB拔插和维修空间。
- [ ] 首次完整系统先卸舵盘与头部负载，连接第06步固件，进入校准，回默认90°。
- [ ] 等两轴停止后断开所有电源，朝正装舵盘与轻质头壳；不带电压着舵盘扭轴。
- [ ] 恢复测试供电，核对“自定义中位”是否适合当前机构；逐次1°微调，确认两轴后保存。
- [ ] 手动检查机械余量与线束牵拉；软件30–150°和60–120°不等于机构安全范围。
- [ ] 正常断电重启后重新读取配置与中位，确认保存确实生效；结果记录在下表。
- [ ] 测试急停X与恢复R；关闭PWM仍保留舵机电源，恢复不保证回中，观察实际轴位置。
- [ ] 全部断电，拔掉USB后才按指南U4改为独立主控5V供电；再做完整系统观察。

网页显示的角度是软件当前值和目标值；SG90没有位置反馈接入本方案，不能把软件90°当作真实轴角的测量。

## Mac候选路线

提供包只带Windows启动器。桌面macOS具备Web Serial的平台条件，但本包在你这台Mac上的USB枚举、复位重连、刷写与校准尚未测试。[Chrome官方说明](https://developer.chrome.com/docs/capabilities/serial)

若已安装可信Python3，可在完整解压目录中用本机静态HTTP服务加载网页。下面仅是待验证操作，当前没有启动服务或连接硬件：[Python官方命令说明](https://docs.python.org/3/library/http.server.html)。

```sh
cd '机器人开发参考库/15_小纸壳机器人/工具包/cardboard-bot-teaching'
python3 -m http.server 39876 --bind 127.0.0.1
```

Chrome打开 `http://127.0.0.1:39876/`；先在无硬件状态确认页面和资源，再分别验证USB与刷写。终端保持开启，结束用Ctrl+C停止。不要直接双击HTML。无法枚举时先查线、板型与权限，不凭“网页打开了”判断可烧录。

## 第一版过关后的顺序

工程建议：先在独立开发目录取得或重写固件，建立可调限位、可观察状态和参数保存；其次制作自己的表情与纸壳模板；最后选一种对话路线，验证说话、倾听、思考的动作区别。课堂版本还需补重复装配、长期运行、学生操作与维修记录，本清单不把这些视为已经验证。
