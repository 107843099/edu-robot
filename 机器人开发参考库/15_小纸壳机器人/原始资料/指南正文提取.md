Windows 入门顺序

把整个 ZIP 解压到一个文件夹。阅读 README.md 和教学使用说明.md，保留所有子目录；不要只取 index.html，也不要在压缩包里启动。

包内指定入口为 start-offline-installer.cmd，它调用同目录 PowerShell 脚本启动本机网页服务，再打开浏览器。使用新版 Chrome 或 Edge，不要直接双击 index.html。实际启动尚未验证。

改线前拔掉 USB 和全部外部电源。刷写时断开主控外部 5V 线、关闭外围电源，仅以数据 USB 连接主控；按 BOOT、RESET 顺序进入下载模式，再选当前模块安装。

浏览器会按 Espressif 原生 USB 303A:1001 筛选设备，通常显示 USB JTAG/serial debug unit。它不会把 COM7 等 Windows 端口号提供给网页。只连接当前一块板；CH340、CP210x 转接板不在该筛选范围。

刷写后关闭安装窗口，按页面恢复外围模块电源并按 RESET；主控仍只由 USB 供电。点击“连接测试”，舵机再点“开始测试”；完整系统使用“连接完整系统”。软件识别成功后仍要亲自观察硬件表现。

重要：说明称默认不整片擦除，但包内安装器正常路径会先执行整片擦除，再按分区写入。这个矛盾已从代码静态交叉核查，未实机试刷。因此再次安装可能丢失保存的中位等数据，不能保证保留 NVS。刷写前记录原有校准数值，刷写后重新检查；不要把正常重启与重新刷机混为一谈。

供电选择与每次通电检查

本页先记录作者 FAQ，再列安全补充。电池方案尚无完整接线图、模块额定输入范围、续航或实物验证，不能直接据此采购并接通。

作者对适配器与电池的说明

现版由适配器接市电，作者描述为输入 220V、输出 12V，再接到多路 DC 电源模块，因此正常运行需要插电。作者提到可使用旧的 12V 适配器；是否适用还取决于下面列出的实物规格。

作者给出的可选电池方向是输出标为 7.4V 或 12V 的锂电池组，采用 DC5521 接头，电源模块不变。FAQ 估计相较适配器可能多花十几至二十几元；这是作者的粗略比较，不是本指南查询的现价，也不构成完整电池及充电器预算。

补充建议 先核对额定值再选电源

旧适配器也要核对输出电压、额定电流、插头尺寸、中心极性、线材状态及电源模块输入要求；“12V”相同不足以证明可替换。选用完好、适配且有合规安全标识的成品电源，不拆修适配器，不接触或改动市电侧。

电池标称电压不等于满电电压。例如常见单节满充 4.2V 的两串锂离子方案可标称 7.4V，满充为 8.4V；这只是解释额定值的例子，不是对作者电池型号的确认。标成“12V”的电池不能据此推定化学体系、串数或满充电压。

选成品受保护电池组及与其化学体系、串数和充电要求匹配的充电器。核对电池满充和放电期间的输出范围、极性、允许电流与模块额定输入范围；DC5521 只描述接头规格，不能证明电气匹配。具体保护需求按电池制造商说明确认。

上述电池安全补充参考 E2 与 E3。这里不提供自组电池、改充电器或绕过保护的步骤，也未确认原多路 DC 模块可用于电池充电。

作者要求的上电与排错顺序

每次通电前检查连线、电源是否正确，确保各板不会互相接触；手不要触碰金属电路。改线先断开 USB 与全部外部电源。错接线可能损坏开发板，不能带电反复试线。

完全无反应时依次回查：模块是否独立测试通过、是否正确进入下载模式、程序是否选对并刷入、是否按说明正确启动、连线是否正确。卡在哪一步，就先回到上一步重新检查，不急着封壳或增加功能。

复刻流程的工程补充

本节是为减少返工而整理的通用制作建议，不是 Made by Z 的原话、原图纸或已验证的原机参数。完成前面的型号与资料核对后，再把这些步骤应用到所选硬件。

一 先定义最小可运行版本

先让一项输入可靠改变一项输出，再逐步加入完整外壳与表情。建议依次通过传感器单测、单个执行器单测、联动测试、机械装配和整机测试。这样出现问题时，可以知道问题来自哪一层。

制作一张接口表：模块名称、供电范围、信号类型、接到哪个引脚、所用库、安装位置。每接一根线就核对一次，不要把线色当成引脚定义。

把下载的程序、依赖库版本、板卡选项和一次成功烧录记录保存到同一项目文件夹。不要同时改接线、改代码、换电源。

二 纸板结构先试装再封口

先做可拆开的纸样，摆入真实电子件后再确定开孔。纸板厚度、舵机本体和转动扫掠范围都会影响最终尺寸，不能单靠视频透视图按比例量取。

把头部、承力连接、底座和检修盖分别编号；标明内外侧、折线和粘接面。先验证对称性与转动间隙，再胶合。

检查舵机轴与纸板连接是否稳固，运动时是否拉扯线束。需要承力的连接处可先用余料试验局部加固方式；不要让胶进入电机、轴承或连接器。

保留可以看到接口、拔插电源和重新烧录的检修口。线束留有转动余量，但不能垂入运动机构。

三 逐级上电与检查

先断电核对极性与供电额定值，再用匹配硬件规格、具备必要保护的低压电源测试。电源规格应由实际模块数据表与负载决定，不能由外观或视频中一根 USB 线推定。

如果实际方案采用普通舵机，Arduino 官方资料提醒：舵机负载可能超过开发板供电能力；需要独立供电时，要按所用板卡和电源的规范建立信号地参考。此原则不等于已经确认原作者的接线拓扑，也不等于可以把所有正极直接并接。见补充来源 E1。

首次测试时拆开外壳，让运动部件无负载或轻载运行；先确认安全的中心位置，再小范围试动，逐步找出不碰撞的机械范围。

发现异常发热、异味、重启、抖动或卡死，应立即断电检查。不要用手强扭带电舵机，也不要通过提高电压来解决卡住的问题。

工具安全：切割垫上用刀，手离开刀路；热熔胶和烙铁放在耐热支架上。纸板远离发热元件和裸露接点。儿童操作切割、热胶或焊接工具时应由成人直接监督。

五 联动逻辑的检查顺序

先确认输入变化，再确认程序判断，最后确认输出动作。双输入场景应明确“左侧触发、右侧触发、两侧同时触发、均未触发”四种状态各自的行为。具体行为必须以核实后的作者程序或自行设计的规格为准。

对阈值附近反复跳动的输入，先固定机械位置与测试环境，再考虑去抖、连续采样确认或滞回。不要用过大的延时掩盖接线或供电故障。

在安全范围内缓慢变化输出，避免机械瞬间冲到极限。显示刷新、输入采样和动作执行应相互协调。

预先定义上电、失去输入、程序异常和关机状态。电源断开后确保机构不会伤人或跌落。

安装器的擦除风险

发现一处会影响复刻的文档与代码矛盾。README 声称默认不整片擦除，release.json 也记录 NVS 不在写入区内；这只能描述分区域写入范围，不能排除安装器先执行擦除。

检查位置 | 静态结果

确认与刷写路径 | _confirmInstall 将标志传下去，先 eraseFlash()，之后才 writeFlash({eraseAll:false})

结论 | 按现有正常 GUI 安装路径，不能承诺保留校准或其他 NVS 数据；未实机验证

刷写前把现有中位、方向与机械状态记下来，刷写后重新做身份检查与校准验收。不要为了保留配置而自行跳过引导程序或修改安装器，除非能独立验证对应版本和恢复方案。正常断电重启与重新刷写是两种操作。

断开网页不一定停止机器人

test-connection.js 对教学测试断开时会尝试发送 STOP；完整系统断开时不会发送同样的停止指令，而提示继续按当前模式运行。因此关闭页面或释放串口不能当作完整系统急停。异常时使用急停并按安全说明切断外围电源；不要依赖网页仍能响应。

串口协议与可验证的控制行为

以下摘取自 test-connection.js 与 device-status.js，是网页侧可读协议，不是建议绕过安全界面直接发命令。串口速率115200，按换行分隔文本命令；设备筛选为 USB VID 303A、PID1001。

用途 | 命令或响应 | 网页侧含义
身份查询 | ?；CB_TEST 或 CB_ROBOT | 核对步骤与版本；完整系统另读能力标记
教学保活 | PING | 教学连接定时发心跳
单舵机测试 | START servo_pan / START servo_tilt；STOP | 身份与OLED应答符合要求后启动；停止命令与实物停止分开确认
运行模式 | 1 / 2 | 正常运行 / 校准
回中 | B / C | 默认90° / 已保存自定义中位；B不覆盖自定义值
1°微调 | A / D；W / S | 水平左 / 右；俯仰上 / 下，实际方向仍按实物验收
保存 | V | 保存两个当前位置为自定义中位
急停与恢复 | X / R | 关闭PWM / 恢复驱动；恢复不会自动回中

网页每500毫秒查询或发送保活，超过约2200毫秒未收到状态就断开连接；首次身份识别等待约4秒。这些是网页端超时参数，不代表已经证明全部固件的失联安全机制，也不能外推为完整系统必然自动停止。

状态行包含模式、两轴当前角度与目标角度、停止状态、驱动状态和配置标记。网页识别了正确固件、收到OLED应答、现场实物动作通过，是三项不同证据。显示“已连接”不能替代观察、轻载试动与异常断电检查。

软件检查不能代替验收

另两项静态边界值得注意：教学页面处理 CB_ROBOT 时只校验版本，未先确认当前步骤确为完整系统，存在错误识别状态的可能；页面切到后台时出现的“测试已停止”文案，也不等于完整系统已发出急停。人工通过勾选不是自动测量结果，也不是不可跳过的硬件安全关卡。

输入与动作的基本关系

初始化指令支持文档GPIO映射；双红外按低电平触发处理，触摸按高电平触发处理，输入稳定判断阈值约40毫秒。正常状态逻辑显示：触摸进入PET；一侧检测进入TRACK并改变水平目标；两侧同时有效时维持水平目标；失去检测后可进入SEARCH扫描。它是静态功能轮廓，尚未穷尽全部计时、显示、随机动作与错误恢复分支。

定位：06-robot 初始化0x21118–0x21186，输入处理0x20072–0x20104，正常状态0x20A52–0x20B86。动作目标受配置边界约束，不代表实际机构一定不会撞限位。

教学心跳与急停的区别

单舵机教学二进制可定位90→85→95→90数组及心跳检查：超过2000毫秒未获保活会停止PWM。水平程序数组0x3E4，检查0x1036A–0x10392。网页2200毫秒连接超时与固件2000毫秒停止条件是不同层级；均未实机计时。

完整系统急停会关闭两路PWM，恢复驱动不自动执行回中；回到正常模式后仍可能继续根据输入运动。关闭PWM不是切断舵机电源，也不是经过认证的机械急停。不要因此省略可随时断开外围电源的操作条件。
