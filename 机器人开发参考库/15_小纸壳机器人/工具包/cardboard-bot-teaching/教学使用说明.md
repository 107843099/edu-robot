# 纸板机器人分步测试

打开本目录的 `start-offline-installer.cmd`，浏览器会打开本机网页。必须使用数据 USB 线和最新版 Chrome 或 Edge；不要直接双击 `index.html`。

不需要先去设备管理器查 COM 号。安装和测试弹窗已按本项目的 Espressif 原生 USB 设备筛选，通常只会显示 `USB JTAG/serial debug unit` 或对应的 USB 串行设备。浏览器不能直接显示 Windows 的 `COM7` 这类编号；首次使用时点击弹窗中的设备完成授权即可。如果同时连接多块同型号 ESP 开发板，请先拔掉其他板，只保留当前要安装的一块。CH340 / CP210x 转接板不在当前筛选范围内。

每一步都按这个顺序操作：

1. 第一次使用新版固件前，同时断开 ESP32 USB 和全部外部电源，把 OLED 永久改为 SDA→GPIO0、SCL→GPIO1，并保持 GPIO8/GPIO9 空闲。屏幕通过后一直保留，以后刷机不用再拔 OLED 信号线。
2. 关闭本步模块外部电源，只接 ESP32 USB。简化版 ESP32-C3 按住 BOOT → 按下 RESET → 松 RESET → 松 BOOT，等待端口重新出现，再点击对应步骤的安装按钮并选择当前端口。写入期间不要复位或拔 USB。
3. 安装成功后关闭刷机窗口，恢复本步模块电源并按一次 RESET 启动固件。传感器步骤点击“连接测试”；舵机步骤再点击“开始测试”。下载模式下不能测试功能。
4. 按屏幕提示观察。确认通过后断电，再进入下一步。

步骤顺序是：屏幕、双红外、水平舵机、俯仰舵机、触摸、完整系统。水平和俯仰舵机每次只接一只，舵盘和纸板头部都不要安装。点击开始后只执行 `90° → 85° → 95° → 90°` 一轮动作；出现嗡鸣、卡住、发热或 ESP32 重启时，立即断开舵机外部 5V。

接线引脚：OLED SDA/SCL 为 GPIO0/1，左红外为 GPIO4、右红外为 GPIO3，水平/俯仰舵机为 GPIO5/6，TTP223 OUT 为 GPIO10；GPIO8/9 保持空闲。逻辑模块使用 3.3V，舵机使用外部稳定 5V，所有 GND 共地；外部 5V 不得接到 ESP32 的 5V 脚。

教学固件不保存校准值。首次装配完整系统时，先断开 USB 和外部电源、取下舵盘及纸板负载；安装完整固件后上电，点击“连接完整系统”→“进入校准”→“恢复默认中位”，等待两个舵机到达默认 90°。再次断电，朝正装回舵盘。默认回中不会覆盖之前保存的自定义中位。装好后重新上电，可点“回到自定义中位”，用水平/俯仰按钮每次微调 1°，确认两个轴的位置后点“保存自定义中位”。若默认中位按钮不可用，请先安装本页最新完整固件；机构已装好时必须确认运动空间，异常立即切断外部 12V。
