# 小纸壳机器人物料接线与机构拆解

接线以提供的 V0.3 工具中 `teaching-flow.js`、教学使用说明和实物接线图相互核对。采购规格来自提供指南的 U1至U3与FAQ；未经实测的商品参数仍按来源记录。准备一台样机，不据此批量采购。

## 完整 GPIO 表

| 模块端 | ESP32-C3或供电端 | 说明 |
|---|---|---|
| OLED SDA | GPIO0 | 与旧版占用GPIO8/9的接法分开 |
| OLED SCL或SCK | GPIO1 | 本包为I2C，不按SPI屏接线 |
| 左红外 OUT | GPIO4 | 左右以机器人自身方向统一贴标签 |
| 右红外 OUT | GPIO3 | 单独遮挡确认左右映射 |
| 水平舵机信号 | GPIO5 | 黄/橙常见，但以实物定义为准 |
| 俯仰舵机信号 | GPIO6 | 单舵机测试时另一只断开 |
| TTP223 OUT | GPIO10 | 铜箔接感应区，不直接接OUT或电源 |
| OLED、红外、TTP223 VCC | 电源模块3.3V | 按V0.3接法，不能把5V数字输出直接视为3.3V安全输入 |
| 两个舵机红线 | 电源模块5V | 舵机电流不经ESP32的3.3V输出供给 |
| 全部模块GND、舵机棕/黑线、ESP32 GND | 公共GND | 信号要有共同参考地 |
| GPIO8、GPIO9 | 保持空闲 | V0.3说明要求；避免下载模式异常 |

GPIO是芯片信号编号，不是从某一边数第几根排针。GPIO2、8、9是启动配置相关引脚，18、19默认服务USB；新增外设前另查板型和资源。[Espressif GPIO官方说明](https://docs.espressif.com/projects/esp-idf/en/stable/esp32c3/api-reference/peripherals/gpio.html)

## 三种供电状态必须分清

| 状态 | ESP32主控 | 外围模块 | ESP32的5V脚 |
|---|---|---|---|
| 下载固件 | 电脑USB | 外部电源关闭 | 外部5V线断开 |
| 浏览器测试或校准 | 电脑USB | 按当前步骤恢复外部3.3V或舵机5V；共地 | 外部5V线仍断开 |
| 脱离电脑独立使用 | USB拔掉 | 电源模块供各外围 | 按指南U4图将模块5V接主控5V；先核对实际板卡 |

工具中的“外部5V不得接ESP32 5V脚”用于USB测试接法；指南U4展示独立使用接法。外围有外部电源不等于主控已接外部5V。换线时USB和全部外部电源一起断开。把电源模块VIN直通端、5V稳压端和3.3V端清楚标记。

## 机构怎样承载两个轴

基座固定下方水平舵机；其上方承载俯仰舵机，俯仰舵盘通过头内支架带动头壳。卷筒身体和四肢主要提供角色造型，不能根据四肢外观推断它会行走。指南图7与图15提供模型和真实装配对照。

工程推断：俯仰轴承担头壳、OLED、红外、触摸与线束负载，头越重或重心离轴越远，负担越大。因此先做轻质头壳、可拆固定、柔软线束，并给转轴附近留松弛弯；实际承载必须试装测量，不能只用SG90商品名称判断。

## 尺寸依据分成两套

| 部件 | S3视频模型，指南记载 | U5模板原数字，单位待确认 |
|---|---|---|
| 头部 | 两条水平边45mm和50mm，高41mm；方向见图6 | 正脸55×45，左右侧45×45，显示孔25×17 |
| 身体 | 高22mm | 长110×高20 |
| 底座 | 宽70mm、长91mm、高35mm | 上盖90×73，侧边40；底部90×70，两侧粘接边各15 |
| 头上盖 | 模型不补齐展开尺寸 | 54×45，两侧粘接边各10 |
| 隔板与垫层 | 以三维位置理解 | 主隔板80×25、侧边10；小隔板40×20、侧边10；垫层35×20按需加厚 |
| 四肢 | 装饰卷筒 | 手臂25×14各2，腿37×18各2 |

模板的两处槽标18×5，前挡板按实际尺寸确定。虚线不要裁断。模板图已经单独提取为[原图](<%E5%9B%BE%E7%89%87/image9.jpg>)，但没有因此取得1比1PDF或可编辑CAD。

不要把两套数字拼成一套施工图，也不要从透视截图补造精确孔位。先确认单位和纸厚，在同一套模板下做纸样；量尺核对底部、正脸和显示窗口等多个位置，再用真实电子件试配。屏幕PCB外廓与发光区、舵机舵盘孔位、接插件拔插空间都需现场确认。

## 装配建议顺序

先做外壳纸样与电子件模块测试，二者可并行；底座先规划主控、电源模块、隔板与线口，电子件可拆装固定；双舵机回默认90°后断电装舵盘；再试装轻头壳和线束，观察各方向活动空间；最后安装铜箔与装饰、校准自定义中位，确认可取下USB和检修后再做永久固定。

此顺序是基于来源结构作出的工程建议。第一版不建议缩小底座、加重头部或同时引入电池与音频，先得到可复测的原型。
