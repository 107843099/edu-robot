# 小纸壳机器人项目资料

这是一款 ESP32-C3 控制、纸板外壳、OLED 表情、双轴头部、双红外与摸头触摸交互的桌面机器人。按你目前的倾向，它应作为第一版实体原型的优先候选：先做出一个可重复装配、会转头和回应触摸的角色，再考虑对话和教学套件。

现有材料足以准备物料、模块测试和机构试装，但还不能称为完整开源工程。测试工具包含网页源码与六套已编译固件，没有单片机 C/C++ 源工程、可编辑结构模型和可确认比例的原始打印模板。本次已读取两份文件，提取22张配图，校验80个解压文件和24个固件文件，并分析部分 RISC-V 指令。没有烧录或实物测试。

整理日期：2026-10-02。来源为你提供的复刻指南与 V0.3 ZIP；指南记载的作者视频和历史评论与本次独立核查分开标注。

## 它的能力和第一版定位

| 内容 | 当前资料支持的判断 | 第一版采用方式 |
|---|---|---|
| 外壳 | 纸板头壳、卷筒身体与四肢、带隔板底座；见指南图6至11 | 保留可拆装和走线空间，角色装饰可以自行设计 |
| 运动 | 两个 SG90 分别控制水平和俯仰；四肢是纸壳造型 | 第一版验证转头、抬头；没有足部驱动或行走机构 |
| 感知 | 左右红外开关量、TTP223 触摸 | 研究“靠近—看向—摸头回应”的局部交互 |
| 表达 | 128×64 单色 OLED 与头部动作 | 对照作者固件完成基线，再研究自己的表情节奏 |
| 对话 | 本包未提供麦克风、扬声器和对话客户端 | 第二阶段另选电脑对话或独立语音板方案 |
| 教学 | 五项分模块固件与一套完整系统固件 | 每步把接线、固件身份、观察结果分别验收 |

“跟随”在这里是两个红外输入引起的水平动作，不等于摄像头追踪、人脸识别、测距或自主导航。固件里的 Wi-Fi 等 SDK 字符串也不能证明本机器人已经联网对话。

## 目前最影响复刻的四件事

1. **安装可能清除校准。** README 声称默认不整片擦除，但实际安装器普通路径先调用 `eraseFlash()`。刷写前记录中位；每次重刷后重新校准。
2. **释放串口不是完整系统急停。** 模拟核查确认完整系统断开时未发 `X` 或 `STOP`，不能把关闭页面当作停止动作。
3. **界面“固件匹配”仍可能误判。** 模拟输入同版本 `CB_ROBOT`，屏幕测试步骤也会接受。每步必须确认对应固件及实物画面。
4. **模板与模型尺寸不同。** 图9 A4模板没有明确单位，嵌入 Word 又有缩放；不能直接打印 Word 页当作1比1模板。先取得原始尺寸依据或量尺校准纸样。

## 为什么值得借鉴

纸板让学生能看见“平面零件如何变成角色”，两个轴与单色屏降低装配复杂度，触摸和左右输入又足以形成可辨认的回应。更值得带入我们产品的是分模块测试、机械中位校准、表情与动作的状态组织，以及可更换纸壳的创作过程。

工程推断：如果外观、供电和中位没有固定下来，先接入对话会增加排错变量。建议把第一版验收限定为作者基线功能与可维护装配；之后在独立开发目录建立自己的固件和角色资源。
