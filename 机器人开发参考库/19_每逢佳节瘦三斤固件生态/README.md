# 每逢佳节瘦三斤固件生态

这份资料涉及C3小智小车、S3音乐RGB小车、月薪喵、群控遥控小车、语音模块、本地音乐服务器、骨架图和充放电模块。独立建为第19项配套生态档案，内部保留版本子目录，并交叉链接小智、曼波、纸壳和小坦克。没有把不同板型的BIN合成一款机器人。

## 怎样借鉴

可以借鉴唤醒与表现功能的取舍、手动/智能控制权切换、语言意图到有限动作的接口、歌曲查询与播放服务拆分，以及屏幕和电池空间的结构思路。若面向课程，先用纸壳完成可控表达，再比较四足与双电机底盘；语音服务与媒体可以复用接口，舵机/电机驱动则分别实现。

C3与S3不是可互换镜像。源码和接线缺口使这些BIN更适合作为功能行为参考；自己开发时需记录引脚、分区、资源版本和控制协议。不能因为同称小智就认为与第08项任意板型兼容，也不能凭同一用户提供的文件夹推断第18项小坦克与此作者同源。

## 授权与验证

主固件ZIP名称明确“未经许可切勿商用”，包内未提供将作者自有固件统一开源授权的文件。保留限制，商业衍生需要取得作者授权。FFmpeg自带GPL只覆盖其分发组件，不能推定覆盖Python服务器、机器人固件、外观和音频。

本次解析镜像头、候选分区与应用描述，检查配图/命令表，并对音乐管理器做9项离线合成检查。没有启动原服务器、下载音乐、训练模型、运行烧录工具或测试实体机器人。
