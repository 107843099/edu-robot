# AlbertMicro 机器小狗 详细资料

几何外壳、屏幕眼睛与四条简单摆腿构成轻量桌宠，可用于研究少量器件怎样形成清晰的角色表达。

## 已核对的硬件与能力

ESP32-S3、4 个微型舵机与 SH1106 OLED。主要代码集中在 AlbertMicro.ino，提供 STL；可通过 BLE UART／串口控制，并有信息屏界面。

对话和控制配套现状：Micro 未看到原生自由对话配套；同作者 Pro 提供训练和轨迹导出。

BLE UART 或串口命令 → Arduino 状态和姿态函数 → 4 个舵机与眼睛；AlbertPro 是独立的 8 舵机仿真训练路线。

## 外观代码与产品思路借鉴

以下为面向后续自研与课程的分析建议。

- 外观：几何机身和大面积脸部让角色易识别，外壳改造可以围绕比例、颜色与装饰展开。
- 行为：将眼睛、姿态和步态参数联系起来，让同一种事件产生连贯的屏幕与身体反馈。
- 教学：轻量工程便于拆解，适合围绕幅度、相位、限位和插值设计可观察的小实验。

## 开发试验建议

先做站姿、摆动和停止，观察动作中能否及时响应新命令；以相同的小功能范围重建自己的可维护实现。

Micro 适合先学习最小机械与角色感；Pro 可作为后续仿真课程。若做对话，应另接语音底座或网关，并用串口/BLE 的动作边界联动，这是新增开发。

## 已知限制和待补资料

4 舵机机构不能与高自由度四足等同。源码中部分姿态含循环延时；未见完整 PCB、系统化材料表或实机可靠性验证。

源码存在、说明中的功能、作者的测试和本次真机验证是不同状态。本次完成资料核查和静态阅读，未编译固件、训练模型或测试实物。
